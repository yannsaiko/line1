# React Chat Application

トーク相手の名前を判定して動的に表示するReact+TypeScriptのチャット画面サンプルです。

## セットアップ手順

1. 依存ライブラリのインストール:
   npm install

2. 開発サーバーの起動:
   npm run dev

## GitHubへのプッシュ手順

1. Gitリポジトリの初期化:
   git init

2. ファイルの追加とコミット:
   git add .
   git commit -m "Initial commit: Add React Chat App with dynamic partner name"

3. GitHub上の新しいリポジトリURLにプッシュ:
   git branch -M main
   git remote add origin YOUR_GITHUB_REPOSITORY_URL
   git push -u origin main
